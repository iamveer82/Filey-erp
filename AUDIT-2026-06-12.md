# Filey ERP — Full Audit Findings (2026-06-12)

Generated by 17 parallel audit agents over 51 files. Theme-level loud styling already fixed centrally (tokens/ui.tsx/index.css) — entries below list remaining production gaps and dead ends.

## src/pages/Overview.tsx

Customizable widget dashboard (drag/drop via dnd-kit, per-widget resize + font/color styling persisted to localStorage) showing KPI metrics, net profit, orders trend chart (recharts), stock breakdown, activity, and AI briefing. Functionally rich and mostly hardened (skeletons, ErrorBanner, empty states, real data), but visually loud (framer-motion staggered springs, yellow gradient chart, bento shadows, dark spotlight card) and carries several a11y/dead-end gaps plus a chart-bucketing data bug.

### Production gaps

- L403-404: customers and quotations state typed `any[]` — untyped data used by GettingStarted props
- L540-598 + L590-595: trend bucketing bug — buckets are deduped into a Map keyed by keyFn, but 'month' (W1-W5 week-of-month keys across a 30-day window spanning two months) and 'quarter' (6 buckets at ~15-day intervals → duplicate month keys) generate duplicate keys; all order counts land in the last bucket sharing a key while earlier rendered buckets show 0, and orders falling in a real bucket whose key was overwritten are silently miscounted — chart shows wrong distribution for month/quarter periods
- L247-249 + L250-256: clickable widgets are plain divs with onClick — no role="button", tabIndex, or keyboard (Enter/Space) handler; whole-card navigation is mouse-only (a11y)
- L377-389: resize handles are pointer-only divs with title attributes; no keyboard alternative and no aria labels (a11y)
- L863-878: 'Add widget' dropdown has no outside-click or Escape close — stays open until an item is picked or edit toggled
- L479-484: startResize attaches window pointermove/pointerup listeners with no unmount cleanup — leaks if component unmounts mid-drag
- L495-496, L499: error formatting `e instanceof Error ? e.message : e` can render '[object Object]' for non-Error rejections
- L946-952: per-widget CSS from localStorage is injected raw into a <style> tag (widgetCss L151-162); values normally come from constrained inputs but hand-edited localStorage can inject arbitrary CSS (self-XSS-class risk, low severity)
- L80, L171-199: dashboard layout persists only to localStorage (per-browser) — inconsistent with the app's Supabase app_settings cross-device persistence pattern used for other settings
- L106: 'categories' KPI counts distinct product categories (L510-513) but links to /suppliers and its label conflates the two — misleading metric/navigation pairing
- L717: conflicting `flex` and `inline-flex` on the same element (period pill bar)
- L503: useEffect calls load() with empty deps while load closes over toast/state — works only because of the known non-memoized-toast convention; fragile if deps are ever added

### Stubs / dead ends

- L769-771: 'Recent activity' card header shows a 'View all →' affordance but it is a non-interactive <span> with no handler, and 'activity' has no WIDGET_LINK entry — clicking does nothing anywhere on the card
- L824-826: 'Top low-stock items' has the same decorative 'View all →' span; it only 'works' because the whole card click navigates to /inventory — the span itself is not a focusable control
- All WIDGET_LINK routes verified to exist in src/modules/registry.tsx (L86 /inventory, L95 /orders, L104 /invoicing, L149 /suppliers) — no broken routes
