# Statistics

From the statistical-analysis and uncertainty-and-units skills in [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) (MIT). Filey explains figures the user already has. It does not invent a test result.

1. Repeat the number, the unit, the sample size, and the comparison.
2. Say what the test can and cannot support, in plain language.
3. A missing number stays missing. Ask for it or mark it unknown.
4. A spreadsheet of the user's own rows can be checked with `sheet`.
