# Scientific writing

From the scientific-writing skill in [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) (MIT).

1. Use the user's results and the sources you opened. A claim needs a source or a label that it is the user's own result.
2. Order it as question, method in their words, result, and limit. Keep units next to every number.
3. Save a long draft with `word`.
4. A medical or dosing question stays a summary of sources, with a note that this is not professional advice.
