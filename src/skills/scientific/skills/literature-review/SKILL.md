# Literature review

From the literature-review and research-lookup skills in [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) (MIT, K-Dense). Filey reads the public web. It does not run lab or molecule software.

1. State the question and what would count as an answer.
2. `search_web`, then `read_web_page` on the primary sources. Name each one.
3. Group what the sources agree on, where they differ, and what you did not open.
4. Do not invent a citation, a measurement, or a result.
