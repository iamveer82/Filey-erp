# Citations

From the citation-management skill in [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) (MIT).

1. For each claim, name the source you opened with `read_web_page` or that the user attached.
2. A reference you did not open is marked unchecked. Never fill in an author, year, or title from memory.
3. Keep one consistent style, the one the user asked for.
