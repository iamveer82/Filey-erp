# Slides

From the scientific-slides skill in [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) (MIT).

1. One claim per slide, with the source or the user's result under it.
2. Build the deck with `slides`.
3. Charts use numbers you were given. Do not draw a result you do not have.
