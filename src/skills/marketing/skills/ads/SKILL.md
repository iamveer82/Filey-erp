# Ads

Covers ads, ad-creative, analytics, attribution, and conversion-tracking from [Marketing Skills](https://github.com/coreyhaines31/marketingskills) (MIT).

1. Start from the product context. Name the platform, the audience, the offer, and the budget the user stated. If they did not state a budget, ask.
2. Draft a small set: one angle, three headlines, primary text, and the landing-page promise. `generate_image` only when they want a visual.
3. Say what would be tracked (the conversion, where it fires) as a checklist. Do not claim a pixel is installed.
4. Filey does not buy ads. Hand the draft to the user. Never submit a payment or change a live campaign.
