# Social content

Covers social, image, and video from [Marketing Skills](https://github.com/coreyhaines31/marketingskills) (MIT). Platform craft lives in the instagram, youtube, and linkedin packs: load the one that matches.

1. Pick the network and the job of the post (proof, offer, or story).
2. Draft the caption. `generate_image` for a graphic, `create_video_draft` for a short video, only when the user wants media.
3. Publish with `schedule_social_post` to an account from `list_social_accounts`. The user approves the send.
4. Reading what is already public is `read_social_page` or `watch_youtube`. A login wall opens in `workspace_browser`; the user signs in.
