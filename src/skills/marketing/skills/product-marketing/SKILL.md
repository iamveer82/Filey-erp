# Product marketing

Adapted from the product-marketing skill in [Marketing Skills](https://github.com/coreyhaines31/marketingskills) (MIT, Corey Haines). Filey keeps the context in memory. Do not copy a page of positioning the user has not confirmed.

1. `recall` for an existing product context. If it is missing or stale, `get_company_profile` and ask only for the gaps: who it is for, the problem, the offer, the proof, and the competitors.
2. Write one short context: audience, problem, promise, proof, offer, and what this product is not.
3. `remember` it with tag `product`. Replace the old entry when the user corrects it.
4. Every later marketing skill starts from this context. If it is empty, load this skill first.
