# SEO

Covers seo-audit, ai-seo, schema, site-architecture, programmatic-seo, content-strategy, aso, and link-building from [Marketing Skills](https://github.com/coreyhaines31/marketingskills) (MIT).

1. `read_web_page` on the URL the user named, and `search_web` for the query they want to rank for. Cite the pages you opened.
2. Report title, headings, intent match, internal links, and whether the page answers the question in the first screen. For AI answers, note if the page states a clear, quotable fact.
3. A content plan is a list of pages: query, reader, and what the page must answer. Programmatic pages need a real data source, not a pile of thin templates.
4. Do not invent rankings, backlinks, or search volume. Schema is a recommendation the user adds to their site.
