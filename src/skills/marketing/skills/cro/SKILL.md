# Conversion

Covers cro, signup, onboarding, popups, paywalls, and ab-testing from [Marketing Skills](https://github.com/coreyhaines31/marketingskills) (MIT).

1. Read the live page with `read_web_page` when the user gives a URL. Say what you could not see.
2. Find the one friction: unclear promise, too many fields, weak proof, or a buried action.
3. Propose one change and how you would know it worked. An A/B test needs a metric, a sample, and a stop rule. Do not invent a lift.
4. Draft the revised block with the copywriting skill. Do not change a live site from here.
