# Filey ERP 2.12.0

Create images and videos directly in Filey AI conversations, using your own provider keys. This desktop update also includes the account, workspace, purchasing and reliability improvements since 2.11.0.

## What's changed

- **Images and videos in chat:** review a request, select Generate, and see image previews or playable video results in the conversation. Download completed images and open video files. Request history survives restarting Filey on the same device.
- **Separate media keys:** configure OpenAI-compatible image APIs or fal image/video models under Settings → AI. Media uses your selected provider's rates and does not spend Filey credits. Desktop keys use the existing secure credential store.
- **Safer generation:** duplicate clicks cannot submit the same request twice. Interrupted submissions are marked uncertain instead of being automatically retried. Image downloads preserve binary data, fixing corrupted results from the previous desktop proxy.
- **Filey AI workspace:** a simpler composer with effort/access controls, an integrated browser panel, and clearer model-connection settings.
- **Business workflows:** a dedicated expense editor with receipt uploads, PDF-tool reliability fixes, improved team invitations and messages, and consistent navigation and loading states.
- **Accounts and storage:** account and subscription controls, subscription refund requests, stronger workspace isolation, portable backups, and batched cloud-sync metadata to reduce backend requests.
- **Automatic plan access:** Billing recognizes account-owned Ultra even before this device has activated. Eligible devices collect paid access on sign-in; Desktop License is replaced by a Devices tab linked from Billing. Checkout errors use customer-friendly messages, and financial actions are never automatically retried.
- **Mobile document previews:** invoices, quotations, purchase orders and receipts fit the screen as an A4 page, with zoom and horizontal scrolling for reading. Preview stamps and bank details follow the exported document layout. Activity Log and Diagnostics tabs are removed from customer Settings.
- **Find your AI wallet:** open it from the account menu, Account & Profile, Billing, or the chat funding menu. Your own model keys remain available without a Filey top-up.

## Service availability

Bring-your-own-key media is available with a valid provider key and any required provider balance. No private provider key is bundled. Image/video generation is not free merely because the Filey interface is available.

The optional Filey AI wallet, shared free-model access and managed-credit video backend are included in the software, but their merchant/provider activation is separate. Credit checkout and shared providers are not advertised as active in this release. The supplied Higgsfield credentials were not saved during setup; no shared Higgsfield key is included. Subscription refunds remain subject to merchant review; AI credit purchases are excluded from that request flow.

## Downloads and updating

- Windows x64: setup EXE or MSI, with signed auto-update artifacts.
- macOS Apple Silicon and Intel: separate DMG installers and signed auto-update archives. These builds are not Apple-signed or notarized.
- Linux x64: DEB and RPM packages; install updates manually.

Updater signatures verify the update's origin; they are separate from Windows publisher signing and Apple notarization. Existing records are preserved by the update. Keep a current workspace backup before upgrading.

## Validation and self-hosting

The pre-release app suite passed 1,657 tests. TypeScript, web build, native compilation and isolated mobile/desktop media-preview checks passed. Billing checks cover automatic second-device activation, duplicate-purchase prevention, account switching, wallet navigation and customer-facing errors. Document checks cover fixed A4 layout, fit width, zoom and legacy Settings links. Release CI reruns app tests and native fixtures before packaging each platform. Media checks used synthetic provider responses; no live paid generation or customer-record changes were performed. Fresh-device installation and real paid provider output remain separate operational checks.

Self-hosted deployments must apply the additive migrations listed in [MIGRATIONS.md](https://github.com/iamveer82/Filey-erp/blob/v2.12.0/supabase/MIGRATIONS.md) and deploy the corresponding functions before enabling their cloud features. See [media setup](https://github.com/iamveer82/Filey-erp/blob/v2.12.0/docs/ai-media.md) for supported providers and device-local history limits.
