# Filey ERP 3.0.10

This desktop update includes the current website refinements and fixes, using the
same application code for desktop, web and mobile web.

- Minimal light/dark controls, cards, tool covers, chat composers and Teams
  messages. Conversation drafts, attachments, retries and scrolling stay with
  their conversation. Choose a profile avatar's shape and colour.
- Direct invoice actions beside Save and Download PDF, a prominent UAE
  e-invoice review, supported identity/tax fields and XML export, and bank
  details below notes across templates. Mobile previews fit the whole A4 page.
- Reliable tool handoff and downloads, password-protected PDF unlocking with
  the current password, conversion cancellation and empty-output checks.
- Fixes for workspace switching, concurrent local sync journals, file cleanup,
  customer matching, mixed-currency statements, payment reads and sales-journal
  totals. Failed transfers retain the current workspace and offer a retry.
- Hardened agent approvals, workspace boundaries, invoice drafts and messaging
  delivery receipts. Desktop WhatsApp and Telegram improvements are included;
  delivery requires the user's configured connection.
- New users choose Local or Cloud on first launch. Existing choices and signed-in
  accounts remain in place. This source also supports the separately tested
  Android and iOS applications.

E-invoice review and supported XML export do not submit documents to an accredited
provider. Existing free local use, plan entitlements and Coin balances are unchanged.

## Downloads and updates

Windows EXE/MSI, macOS Apple Silicon/Intel DMG, and Linux DEB/RPM installers are
included. Updater packages use Filey's existing signing key. Linux package
installation may require administrator authentication.

Older Linux AppImage installations must move to the DEB or RPM download manually;
the updater no longer offers them an incompatible package. macOS downloads remain
without Apple notarization, as in the previous release.
