# Filey ERP 3.0.21

Optional electronic invoicing details now appear within the chosen invoice layout, without an automatic separate details supplement. Reuse saved customer and supplier identities or enter the details on an invoice. Filled fields appear in previews, PDFs and shared invoices; empty fields stay hidden. Ordinary drafts remain available without these details, while structured XML export still checks its requirements. Saved payment instructions, per-item tax rates and exchange-rate metadata carry through to invoice outputs.

All 52 built-in invoice layouts support inline UAE details, including invoices in foreign currencies. Company addresses, TRNs, phone numbers, email addresses and identifiers remain together. Custom calculation columns such as T.Liters also appear in the Professional layout. PDF export detects content that exceeds the paper and asks for a page break or layout adjustment instead of silently cutting it off.

Invoice creation recovers uncertain saves using the original request and confirms the saved document before reporting success. Large company artwork no longer overwhelms cloud audit records. Navigating between sections keeps the active AI workflow available, and retries preserve the requested prices, quantities and custom calculations.

New invoices and copies reserve their number on the first save instead of when the editor opens. Transport retries reuse the same reservation, and reopening an already converted quotation does not reserve another number. Existing document numbers and reservation history are preserved.

Use Filey's normal updater; uninstalling is not required. Existing local data is preserved. Self-hosted cloud installations must apply `supabase/2026-10-08-audit-artwork-metadata.sql` and `supabase/2026-10-08-supplier-invoice-details.sql` after prior migrations. The supplier upgrade adds optional metadata without changing row access policies. No new dependency is added.
