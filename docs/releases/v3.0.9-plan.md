# Filey ERP 3.0.9 release

This includes the unpublished 3.0.8 desktop fixes and the expanded country UI.
Keep the existing v3.0.8 tag and draft unchanged; its build was cancelled before
publication when the country-label scope expanded. The public updater was 3.0.7
at the start of this release.

1. Validate the shared desktop/web country forms, bank identifiers, saved document snapshots, phone handling and tax labels. Keep ledger currency accurate; country labels are not statutory accounting support.
2. Run typecheck, full frontend tests, lint and production build. Verify mobile preview geometry in WebKit and Chromium using production CSS. Do not change customer records, run payments or send messages during testing.
3. Require CI including disposable RLS, browser tools and edge-function checks. Merge the checked PR and tag its merge commit v3.0.9. Use the existing release workflow with native storage/security checks.
4. Require Windows EXE/MSI, Linux DEB/RPM and Intel/Apple Silicon Mac installers. Verify version metadata, architecture, digests, updater URLs and cryptographic signatures against the unchanged public key before publishing the draft as latest.
5. Verify the public updater serves 3.0.9 and check production web deployment separately. Leave the stopped release automation stopped.

There is no SQL migration. Desktop local snapshot replacement is transactional;
browser storage rolls back write failures but is not crash-atomic. Failed mode
transfers retain the source store and offer retry. Local-only Basic pricing and
features from piratuks/invoice-builder are proposals, not changes in this patch.
