# Filey ERP 3.0.14

This patch improves document accuracy, protects workspace file transfers and
makes AI setup and connections clearer. It also includes the latest profile
mascots already available on the website.

- AI context preparation can be stopped immediately and no longer waits indefinitely for business data. Connection setup, working and approval states are clearer.
- Team attachment transfers stay bound to the account and workspace that started them.
- Pending invoice, receipt and purchase-order saves protect fields from being overwritten. Receipt retries retain a successfully saved record after a list refresh fails.
- Receipt dashboards count confirmed payments; purchase-order totals stay separated by currency. Invalid sales-order lines and unnamed priced PO lines show actionable errors.
- Existing inventory counts use Stocktake's conflict-safe adjustment workflow. Delivery documents preserve edits when company details load slowly.
- Signature tools ignore obsolete uploads. Letter editing and PDF output use consistent self-hosted fonts.
- Built-in connections no longer repeat unrelated utilities, and Telegram setup instructions match the installed app.

Local business records remain on the device. This patch adds no runtime
dependency or database migration. WhatsApp still requires pairing the desktop
app with the user's phone; browser Filey cannot pair an account.

Receipt creation after a completely lost server acknowledgement remains an
ambiguous outcome. Check the saved records before retrying. Physical iOS
keyboard/touch behaviour and real messaging delivery require device acceptance
testing.
