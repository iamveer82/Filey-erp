# Filey ERP 3.0.19

Filey AI retains financial fields when reading tool results, including custom quantity multipliers and manual amounts. Invoice reads provide computed line amounts and totals, preventing the agent from calculating an answer from an incomplete invoice response.

Includes the invoice workflow fixes prepared for 3.0.18: faster cloud saves with large company artwork, atomic document writes, fresh verification and recovery of uncertain saves using their original receipts. Authorized retries preserve the original number, quantities, prices and custom calculations in cloud and local mode.

Standing preferences have space in the agent's memory context, with explicit recurring invoice choices saved for later requests. Current instructions take priority. Damaged memory is preserved, and preferences remain scoped to the device, account, workspace and storage mode.

Install through Filey's normal updater; uninstalling is not required. Existing local records and settings are preserved. Self-hosted cloud installations must apply `supabase/2026-10-07-document-save-performance.sql`; the local collection format requires no destructive conversion. No new dependency is added.
