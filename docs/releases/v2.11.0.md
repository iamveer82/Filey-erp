# Filey ERP 2.11.0

This update connects CRM follow-ups with quotations and invoices, refreshes the document and tool workspaces, and improves local/cloud reliability.

## What's changed

- **CRM:** company, contact and deal drawers; a Today queue; linked sales documents; reviewed bulk edits; duplicate hints; custom fields; and editable AI requests with record context.
- **Sales documents:** compact invoice details, templates before editing, clearer billing details, and quotation conversion that preserves currency, terms and pricing. Retrying conversion returns the existing invoice.
- **Letters:** a compact editor with consistent controls and an editable letter name that follows the document into previews, searches, sharing and PDF filenames.
- **PDF tools:** distinct tool covers, clearer upload/edit/export flows, improved brush and text editing, document organization, signatures, and stable multi-page previews.
- **Filey AI and sharing:** contextual requests, desktop browser/computer controls with action checks, PDF attachment previews, and sharing history that distinguishes drafts, handoffs and observed sends.
- **Workspace reliability:** account/organization-scoped caches, failed-save recovery, stale-workspace protection, password recovery improvements, and country-aware document fields.

## Downloads and updating

- Windows x64: use the setup EXE, or MSI for managed installation.
- Linux x64: DEB and RPM packages; install updates manually.
- macOS Apple Silicon: ARM64 DMG. This build is not Apple-signed or notarized; Intel Mac installers are not included.

The Windows/macOS updater uses signed update artifacts. This is separate from Windows publisher signing or Apple notarization. Back up your local workspace before upgrading.

## Cloud and self-hosting

The hosted Filey project has the required international, work-items, CRM and quotation-conversion schema updates. No customer records were rewritten during this release deployment.

Self-hosted Supabase deployments must apply `supabase/2026-09-12-crm-sales-workflow.sql` after the existing migrations. The new conversion RPC runs with the caller's permissions, checks the current organization, and commits invoice header, lines and quotation status together. See [deployment instructions](https://github.com/iamveer82/Filey-erp/blob/v2.11.0/docs/SUPABASE_DEPLOY.md).

## Validation and limits

1,474 frontend/service tests and six native Rust tests passed. TypeScript, production build and lint passed; lint retains 544 warnings. The cloud conversion SQL passed isolated PostgreSQL rollback, ownership, workspace, retry and concurrency checks; hosted function permissions were verified afterward.

Live email/WhatsApp/SMS delivery, fresh-device upgrades, full backup/restore drills and cross-device sync were not exercised with customer records. External providers still require users' accounts, local models or their own keys and may charge usage fees. No private provider keys are bundled. Country-aware documents do not constitute full statutory localization; the accounting ledger remains AED. The existing `pptxgenjs`/`image-size` dependency findings remain documented in the [PDF dependency review](https://github.com/iamveer82/Filey-erp/blob/v2.11.0/docs/pdf-dependency-review.md).
