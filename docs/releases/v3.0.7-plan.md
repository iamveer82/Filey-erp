# Filey ERP 3.0.7 release

1. Resolve the storage mode the app actually uses through a single shared helper, so every account-scoped lookup (document templates, assistant storage, image library, CRM saved views, bank/cheque/email settings) stops returning "not signed in" on a web build that recorded no mode. Centralise the Supabase project configuration in a leaf module so the mode layer can read it without an import cycle.
2. Replace the two-card workspace chooser with one switch. Enabling cloud asks for consent, uploads only non-empty tables, and reports a partial upload without switching. Disabling never uploads. Point every error at the account that is actually missing instead of saying "sign in to this workspace".
3. Offer the pre-account device template cache back to the signed-in device owner through a one-tap restore, keeping the original blob until the write succeeds.
4. Open the document preview at a legible zoom on narrow screens and keep Fit width as an explicit whole-page action. Lock page zoom on the app shell so a pinch-zoom cannot corrupt the measured page fit. Do not reflow the A4 sheet in any mode.
5. Composite stamp and signature marks onto the exported PDF page with canvas drawing, because iOS WebKit drops images captured through the SVG foreignObject. Preserve opacity, inset crop and multiply blend, leave layout artwork on the existing capture path, and never let one unreadable mark fail the export.
6. No schema migration. Read-only verification confirmed `app_settings` already carries `org_id` and `sync_revision` and that its RLS policies are correct. Tag the merged commit `v3.0.7` so the desktop updater picks it up, and confirm the web deployment separately from the desktop release.
7. The stamp/signature export fix is verified by stubbing the page capture to return a blank page, so a mark can only reach the file through the new compositing path. Confirm on a physical iPhone before or alongside rollout, since no iOS device is available in CI.
