# Filey ERP 3.0.6

- Choose device or cloud versions once to reconcile overlapping records across the saved workspace. Records found on only one side are retained, and later edits continue to sync when automatic sync is enabled.
- Reconnect eligible records from your own retired workspace without changing their IDs or document links. Preserve older unlinked invoice rows as private owner data.
- Save desktop sync choices and their upload queue together, and keep pending changes visible when another edit arrives during sync.
- Ask Filey AI to hide an invoice's logo or apply your saved stamp and signature. These controls affect the selected invoice without changing company-wide branding.
- New stamps and signatures start at 100% opacity. Document editors share clearer preview, size, crop and reset controls; existing opacity settings are preserved.

To reconcile existing conflicts, open Settings → Data & Storage, connect the same Filey account and choose **Use this device's changes** or **Use cloud changes**. Keep **Sync changes automatically** enabled for ongoing synchronization. Cloud changes are picked up on return to the app and during periodic checks; instant live streaming is not part of this patch.
