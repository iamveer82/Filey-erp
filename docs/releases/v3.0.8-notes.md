# Filey ERP 3.0.8

- Turn on cloud storage to save pending device changes before switching. Turn it off to download the latest cloud records and files before returning to this device. If a transfer cannot finish, your current workspace stays open with a simple **Try again** button.
- Desktop cloud downloads commit the complete workspace together, protecting existing records if storage fails. Unchanged records and files are reused to reduce repeat downloads.
- Company fields follow your country: bank identifiers, phone hints, tax fields and default currency. India includes optional registration details and private document storage. Changing country keeps your existing details, and the default currency remains editable.
- New documents use your company's currency. Existing documents keep their own currency and country-specific bank labels.
- Invoice previews fit the phone screen without cropping the page or moving the preview off-screen. Zoom remains available.
- Signup retains the password you chose through email verification, including retries for an unconfirmed account.

No database migration is required. Internet access is required to finish cloud transfers; offline editing remains available on this device.
