# Filey ERP 3.0.18

Fixes slow cloud document saves with large company artwork. Invoice headers and lines stay in one atomic save, with existing ownership and access checks preserved.

Filey AI now verifies uncertain invoice saves against their original receipt before creating another document. Authorized retries keep the original number, prices, quantities and custom calculations in both cloud and local mode. A timeout no longer leads to unsupported claims that nothing was saved, or to a substitute quotation or order.

Invoice verification uses fresh records instead of cached snapshots. Existing local documents and settings are preserved. Install through Filey's normal updater; uninstalling the app is not required.

Filey AI gives standing preferences room in its memory context and saves explicit recurring invoice choices. Current instructions take priority. Damaged memory data is preserved instead of silently overwritten. These preferences remain scoped to the current device, account, workspace and storage mode.

Self-hosted cloud installations must apply `supabase/2026-10-07-document-save-performance.sql`. The current local collection format already supports these fields and requires no destructive data conversion. This patch adds no dependency.
