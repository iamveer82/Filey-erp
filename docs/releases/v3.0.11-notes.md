# Filey ERP 3.0.11

This update brings the current website and cloud workflows to desktop, with a
Word-style Letter editor and safer document handling.

- Write letters directly on an A4 page with a formatting ribbon, font and
  paragraph controls, lists, company letterhead, signatures and stamps. Existing
  letters remain readable and issued copies stay unchanged.
- Search the actual letter text and let Filey AI draft or revise letters while
  preserving formatting during unrelated changes.
- Includes the current Filey AI, invoice, packaging list, wallet, local/cloud
  storage and security fixes already released on the website.
- Updated vulnerable document-conversion and MCP dependencies. Android startup
  handles carrier configuration changes without interrupting the native bridge.

Sign in to the same Filey account and select your existing Cloud workspace to use
your cloud data. Local records stay local until you explicitly choose **Upload
and use cloud** in Settings → Data and storage.

Windows EXE/MSI, Apple Silicon and Intel macOS DMG, and Linux DEB/RPM downloads
are included. Updater packages retain Filey's existing signing key. Older Linux
AppImage installations require a manual move to DEB or RPM. macOS downloads
retain the existing lack of Apple notarization.
