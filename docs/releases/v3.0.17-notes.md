# Filey ERP 3.0.17

Image-based AI tasks keep the current attachments available while the agent looks up customers and prepares documents. Every attached image is read; an unreadable image stops the request with guidance instead of silently omitting it.

Large saved tool results are retrieved in small pages, preventing a full tool catalogue from overwhelming the next AI request. Known request-size and connection failures retain helpful guidance without exposing provider details or automatically repeating billable requests.

No database migration or new dependency is required. Reattach images when retrying an older failed conversation; previous image uploads are not stored in chat history.
