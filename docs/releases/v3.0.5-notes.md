# Filey ERP 3.0.5

- Recover an expired cloud sign-in automatically when switching from this device to Filey Cloud, including the "token has invalid claims: token is expired" error.
- Renew the session and retry only a database or file-storage request rejected for an expired token. Concurrent requests share renewal; failed network requests are not replayed automatically.
- Keep the original account and pending device records protected if sign-in expires, changes or cannot be renewed. Settings now updates its connection state and offers reconnection instead of a stale Connected label.
- Check new WhatsApp self-chat messages against WhatsApp server time so a mis-set desktop clock does not silently discard new tasks. Old history, duplicates and non-owner messages remain blocked.
- Send typing updates while WhatsApp requests are pending and acknowledge longer requests after two seconds. Simple text greetings reply immediately without a model call; typing stops on completion or timeout. WhatsApp may not display typing in Message yourself, so the acknowledgement also confirms receipt there.
- Use recognizable History and Browser icons in the Filey AI toolbar.

This update does not switch workspaces, upload records, resolve conflicts or change your automatic-sync preference on installation. After updating, retry **Upload all local data** or **Switch to Filey Cloud**. If your saved sign-in can no longer be renewed, reconnect the same Filey account under Cloud sync first.

No cloud schema migration or credential changes are required.

Keep your computer's automatic date and time enabled for reliable sign-in and messaging. Live phone-to-agent replies and file receipt are separate from automated transport checks.
