# Filey ERP 3.0.3

- Simplify Integrations and Filey AI with clearer connection states, a compact composer and an integrated browser panel.
- Harden WhatsApp owner verification, duplicate detection, cancellation and session-bound replies and file delivery. Improve self-chat handling and pairing guidance.
- Improve agent tool discovery, argument validation, task receipts and long-task context. Built-in browser tools can open websites without a social API key.
- Add screenshot-based hover, drag and horizontal scrolling to Windows computer tools. Existing permissions, approvals and stop controls still apply.
- Add clearer access to AI-credit funding and simplify conflict resolution with a choice of local or cloud versions.
- Improve company-profile sync and saved signature/stamp availability across storage modes.

Existing records remain preserved. Conflicting records need your explicit choice; upgrading does not select a version for you. WhatsApp pairing requires the desktop app to remain open and connected and uses an unofficial client. Browser interaction requires a vision-capable model; opening URLs does not. Optional agent computers remain browser profiles, not virtual machines.

Updater signatures are separate from Windows publisher signing and Apple notarization. This patch does not enable unconfigured paid providers or include shared API credentials.
