# Filey ERP 3.0.13

This desktop patch fixes local saves and includes the workspace-access and
security updates already released on the website.

- Restored local saving by implementing and registering the native storage
  command used by the app. Records and the sync journal save together, with
  conflicts and failed writes preserving the previous data.
- Removed team members return to their own workspace and retain their personal
  account. Company access remains revoked.
- Filey refreshes workspace access after reconnecting or returning to the app,
  and keeps permissions and cached records tied to the correct workspace.
- Updated image-processing dependencies with security patches and fixed
  WhatsApp attachment processing in desktop builds.

Existing local records stay on your device. The desktop auto-updater and
platform downloads continue to use Filey's updater signing key.

Windows EXE/MSI, Apple Silicon and Intel macOS DMG, and Linux DEB/RPM downloads
are included. Older Linux AppImage installations require a manual move to DEB
or RPM. macOS downloads retain the existing lack of Apple code signing and
notarization.
