# Filey ERP 3.0.1

- Faster local-to-cloud uploads: send up to 50 records per request and save acknowledgements together. A failed record no longer keeps successful records in the retry queue.
- Clearer sync recovery: distinguish conflicts, missing links, permissions, file uploads and connection errors. Preserve records belonging to another company instead of silently moving them.
- Plan and configured AI-credit purchases now show an order review before opening secure checkout. Desktop opens the system browser; mobile and web use the current tab. Payment status always comes from the server.
- Remove unreachable UI files and consolidate duplicated document, statement and contact components.

Existing customer records are preserved. Legacy conflicts and records with missing invoice links still require review; this update does not guess relationships or overwrite another workspace.

Hosted AI credit purchases remain unavailable until the funded provider, published products and webhook configuration are complete. Bring-your-own-key options are unchanged. No purchase is required to install this patch.

Windows and macOS updater artifacts must pass signature verification before publication. Physical iPhone checkout and a fresh-profile installed Windows UI smoke test remain separate manual checks; automated app, browser and database checks do not substitute for them.
