# Filey ERP 3.0.2

- Preserve automatic-sync preferences when switching between local and cloud storage. Stop pending transfers safely if the account or workspace changes.
- Refresh plan and AI-credit payment status when returning from secure browser checkout to the desktop app.
- Improve WhatsApp pairing, reconnects, owner verification and delivery of generated PDFs, images and other files. Incoming attachments stay connected to their original task and approval.
- Add optional per-conversation browser profiles for Filey AI. Agent computers remain off until enabled; regular computer tools remain available under the user's existing access settings. No Docker required.
- Improve payment-receipt stamps/signatures, plan enquiries and backend job handling.

Your existing records are preserved. Switching storage does not automatically merge unsynced records or resolve conflicts. WhatsApp QR pairing requires the desktop app to remain open and connected; it uses an unofficial client. Agent computers are browser profiles, not separate virtual machines.

Validation: 1,715 app tests, 87 backend tests, disposable PostgreSQL permission/accounting checks and a production build passed before release preparation. The production schema audit reported no missing schema items; all 12 backend functions are deployed. Release CI and signed installer verification must also pass before publication.
