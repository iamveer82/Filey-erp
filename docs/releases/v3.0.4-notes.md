# Filey ERP 3.0.4

- Introduce Paper, Filey's AI credit currency, with its own mascot and clearer wallet access from chat, Settings and the account menu. **1 Paper = US$1**; existing balances keep their value.
- Choose named paid or free OpenRouter models, search the catalogue and review usage rates before starting a task. Paid chat uses the selected model and provider-reported cost with no Filey usage markup. Free requests never switch to paid models.
- Add support for custom Paper top-ups from $5 to $100 where checkout is configured, with the existing $0.50 service fee shown separately before payment.
- Improve compatibility with current OpenRouter pricing tiers, image inputs and reasoning-enabled agent tool calls. Spending limits, account isolation and personal API keys remain supported.

This patch retains the agent and WhatsApp security improvements in 3.0.3. QR-paired WhatsApp needs the desktop app open and connected; it does not run independently in the mobile website. Model and provider availability still apply. Live phone-to-agent replies and PDF receipt are separate from automated checks and must not be inferred from a Connected label.

Hosted paid AI and top-ups appear only when the provider and payment products are configured. This release does not activate unconfigured providers or include shared credentials. Upgrading does not edit customer records or reset WhatsApp pairing. Updater signatures are separate from Windows publisher signing and Apple notarization.
